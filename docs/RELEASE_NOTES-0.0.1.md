# 01Code 0.0.1 Beta 发行说明

日期：2026-11-15

## 下载与运行

- Windows x64 发行包解压后运行 `coding01.exe`。
- 首次启动会从 NullClaw 官方 GitHub Release 下载当前平台的运行时，并校验 SHA-256；失败会在“设置 → 运行环境”给出错误，可重试。
- 客户端仅支持网页登录，不提供 API Key 手动填写入口。登录后在输入框右下角选择模型和思考强度。

## 本轮更新

- 网页设备登录：浏览器确认验证码后自动保存设备凭据、启动 NullClaw、同步账户、授权设备和模型列表。
- 登录进行中不再重复生成验证码、浏览器页或叠加遮罩；单实例启动会聚焦已有窗口。
- 模型选择移至输入框右下角，完整模型列表向上弹出；模型名称旁显示当前思考强度。
- 思考强度五档（最低 / 低 / 中 / 高 / 最高），映射到 NullClaw `reasoning_effort`，支持 `Ctrl+T` 打开模型弹层。
- 访问模式选择移至添加文件按钮旁：
  - 普通模式：有变更时询问是否同意。
  - 自主模式：有风险时询问。
  - 完全访问：不再询问，风险自负。
- 支持流式输出与工具调用状态卡片；工具名、路径、状态、执行中动画统一排版。
- NullClaw 停止时输入框提示“网关已停止”，发送按钮禁用；启动后自动恢复。
- 账户卡片精简为用户名 + 余额圆角标签；授权设备名称统一为 01Code。
- 修复遮罩点击后置顶、模型弹层右侧裁切、思考强度最高时滑块被裁切、点击滑块导致弹层关闭等问题。
- 历史写入保留上一份有效快照，主文件损坏时自动回退；异常退出后会清理受管运行时残留进程。

## 已知边界

- 模型能力、计费与上游可用性由言灵中转及其上游决定；上游返回 `渠道暂不可用` 时客户端会原样显示错误。
- 当前官方 WebChannel 不保证完整工具审批往返；工具权限以 NullClaw 原生安全策略为准。
- 完全访问会绕过 NullClaw 的命令与审批限制，仅在可信本地环境使用。
