# 01Code 0.2.1 / R2 修改与验证说明

日期：2026-11-08。承接已交付的 0.2.0 修复版；原始远端基线为 `0a4693e`。本次源码版本升至 `0.2.1`，没有推送远端或创建 Release。

## 本轮修复

- 设置页适配 640×420 最小窗口：窄窗口横向页签、内容独立滚动、固定保存区；桌面保留左侧导航。聊天正文与输入区居中并限制阅读宽度，长会话标题和模型名称裁切，任务计划可折叠。
- 中文输入法组合输入期间不触发 Enter 发送；空消息不再重建连接。
- 直连 Agent 增加 `set_plan` 原生工具，支持最多 16 步的待办 / 进行中 / 已完成状态；计划按会话保存和恢复。提示词保持简短，并明确真实进度与验证要求。
- 更换项目、运行模式后保留未发送草稿和附件，创建独立上下文；回看其他项目的会话后发送，会为当前项目新建会话，避免把旧工具上下文送往不同目录。旧格式历史仍可读取；缺少项目元数据的旧 Agent 会话在继续执行时创建新会话。
- 修改上游地址后清除过期模型目录；跨来源或暂时无效地址清除 API Key 和 Key 环境变量，覆盖清空再粘贴 URL 的情况。
- 网关同步不再把原上游密钥留在已变更地址的配置中。只继承同一完整端点的唯一已有凭据，歧义时不猜测；同步失败保留原文件。客户端设置保存失败时明确说明网关已同步的部分结果。
- WebSocket 地址校验集中处理，省略端口时同步与连接均使用标准端口；本地启动拒绝端口冲突、端口重复与未经配置的 WSS 启动。
- 网关和本地命令共用进程树所有权。Unix 结束进程组，Windows 使用关闭即终止的 Job Object；正常退出、命令超时和取消均清理自有子进程。只允许重启本客户端启动的网关，停止完成后再启动；就绪探测可取消。
- 任务与扩展操作执行时锁定重复请求，避免重复创建、并发修改及结果被覆盖。
- 更新检查 / 下载支持取消。取消与进入安装阶段通过原子状态切换互斥；取消后的迟到结果不提供安装入口。交接文件限制大小、目录、来源、平台、摘要和父进程范围，失败后仅重启已验证的原程序路径。
- 更新备份先写临时文件并同步，再原子替换，保留一份上一版本。下载请求设连接、读取及总时长边界；取消可能等待当前网络读取结束。
- 只把类型为 `image_url` 的图片块转换为附件引用；普通文本中的 data URI 和保留前缀保持原文。发现同摘要缓存损坏时重新保存。
- 历史写盘成功后才裁剪内存会话，写入失败保留原会话；使用有界序列化和借用快照，减少复制并把历史 JSON 限制在 20 MiB。
- 清理附件时保留 `history-recovery.json` 引用；恢复文件损坏或过大时暂停删除附件。网关配置读取限制 4 MiB，不先读入无界文件。

## 本轮验证

- 默认回归测试、格式检查、Clippy 严格检查及 Linux 发布构建结果见同包 `VALIDATION.json`。
- 默认测试覆盖完整的计划工具调用及工具结果继续生成、项目上下文隔离、保存失败和恢复后裁剪、URL 清空 / 粘贴凭据边界、网关占用端口、取消下载后禁止替换、交接路径、普通文本附件识别、损坏缓存和恢复附件保留。
- 真实网关独立测试：官方 NullClaw `v2026.5.29` 的 Linux x86_64 原始二进制，下载后验证官方 SHA-256 `966c524d3816531371e8657ffc84c40f47d94db89f6c70e816adce983e6d1f0a`；使用客户端实际的 `merge_config` 生成隔离配置、本地模拟上游，完成真实 WebChannel 认证、会话绑定和回复。测试通过后清理自有网关进程。
- Linux 原生窗口实际检查设置、更新与存储、聊天和任务计划；在 1280×800 与 640×420 窗口复核。六个设置页另有 640×420、960×640、1440×900 布局回归。
- Windows 进程树模块使用 `x86_64-pc-windows-gnu` 目标单独交叉类型检查通过；这不是 Windows 整体构建或运行验证。

## 使用与验证边界

设置中可分别从官方 GitHub Release 更新 NullClaw 和 01Code。01Code 必须先由维护者应用源码并发布与 Cargo 版本一致的 `v0.2.1` tag，生成更新器识别的资源。此交付没有发布或安装到用户正式目录，ZIP 不含 Windows 可执行文件。完整 Windows GUI、Windows / macOS 自更新重启仍需对应系统验证。

没有用户的生产上游凭据，生产模型、计费和供应商差异未实测。NullClaw 当前 WebChannel 不保证发送内部工具事件，也没有保证后端取消接口；客户端不伪造轨迹，停止接收不会宣称后台任务已停止。直连 Agent 的工具执行、审批和计划由客户端实现。

轻量化以减少历史复制、限制数据大小、复用图片、释放纹理和清理自有进程为主；没有宣称固定运行内存上限。Shell 以当前用户权限执行，并非系统沙箱；停止不会回滚已经完成的修改。

# 01Code 0.2.0 修改与验证说明

基于 `Cheerimy-Studio/01Code` 的 `0a4693e` 修改，日期 2026-11-08。

## 主要改动

- 增加 OpenAI 兼容直连对话与本地 Agent；支持真正的 SSE、思考内容、原生工具调用及工具结果继续生成。
- 多上游管理、独立凭据、模型目录获取、模型选择和手动模型 ID。
- Agent 提供列目录、读文件、字面搜索、完整写入、精确替换与命令执行；写入和命令逐次审批。精确替换必须只匹配一次。
- 对话 / 轨迹切换，工具参数与结果展开，变更预览、代码复制、会话搜索、重命名与 Markdown 导出。
- 修复发送后未进入忙碌、重复发送、文件附件不能单独发送、空 final 丢失增量、工具结果错误关联、审批超时和悬挂状态等问题。
- 连接失败直接显示错误，不再自动生成演示回复。演示仅由开发变量显式开启。

## NullClaw 集成

- WebChannel 的连接级会话绑定、Bearer 升级认证、`auth_token` 与配对 `access_token` 区分。
- 设置中同步全部上游、当前模型、工作区及本机 WebChannel；保留未知配置、其他渠道、已有加密凭据和权限设置。同步 API Key 需要单独勾选，并明确提示其存储方式。
- 一键启动、连接状态、就绪后重连、停止自有网关、内存日志、诊断、技能列表、网关历史、Cron 创建 / 暂停 / 恢复 / 运行 / 删除。
- 支持 `NULLCLAW_HOME`、`NULLCLAW_BIN` 与自定义可执行文件。客户端退出会停止自己启动的网关，外部网关不受管理。
- 设置中从官方 GitHub Release 安装或更新 NullClaw；安装前检查系统、架构、大小、可执行文件格式与 SHA-256，旧程序保留一份。

## 01Code 更新

- 从本项目官方 Release 检查新版本，下载并校验，使用交接进程等待原程序退出后原子替换并重新启动。
- 单实例锁防止两个客户端同时修改配置或更新程序。安装失败记录原因，保留旧文件和备份。
- GitHub tag 发布工作流生成更新器识别的 Windows / Linux 原始二进制。仓库没有 Release 或资产缺少校验值时，界面不会宣称可以自动升级。
- 本次没有创建远端 Release，也没有推送代码；发布流程需要应用本次源码后，由项目维护者推送与 Cargo 版本一致的 tag。

## 资源占用

- 同一图片按 SHA-256 仅保存一份，历史和工具上下文使用引用；按需还原当前会话缩略图，离开会话后释放其图片纹理。
- 空闲及等待审批时使用低频刷新；消息布局复用缓存，屏幕之外的稳定消息跳过重排。
- 流式事件队列设有背压，响应、上下文、文件操作、搜索范围、命令输出和日志均设置上限。
- 历史保留数量可配置，当前会话始终保留；历史文件上限 20 MiB，异常索引暂停自动写入，可先备份再重建。
- 设置显示实际分类磁盘占用，并提供未引用附件、失败下载和更新缓存清理。新设置与连接参数合并原子保存。
- 不再重复载入同一份中文字体；窗口图标与 DPI 使用 eframe 的原生处理，移除按窗口标题查找和强制修改尺寸的代码。
